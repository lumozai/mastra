# LumozExporter

Sends Tracing data to Lumoz using OpenTelemetry and OpenInference semantic conventions.

## Constructor

```typescript prettier:false
new LumozExporter(config: LumozExporterConfig)
```

## `LumozExporterConfig`

```typescript
type LumozExporterConfig = Omit<OtelExporterConfig, 'provider' | 'exporter'> & {
  apiKey?: string
  endpoint?: string
  baseUrl?: string
  headers?: Record<string, string>
  subtenantId?: string
}
```

Inherits from `OtelExporterConfig` (excluding `provider` and `exporter`), which includes:

- `timeout?: number` - Export timeout in milliseconds (default: 30000)
- `batchSize?: number` - Number of spans per batch (default: 512)
- `logLevel?: LogLevel | 'debug' | 'info' | 'warn' | 'error'` - Log level (default: WARN)
- `resourceAttributes?: Record<string, any>` - Custom resource attributes

## Usage

### Zero-Config (using environment variables)

```typescript
import { LumozExporter } from '@mastra/lumoz'

// Set LUMOZ_API_KEY. LUMOZ_ENDPOINT is optional.
const exporter = new LumozExporter()
```

### Explicit Configuration

```typescript
import { LumozExporter } from '@mastra/lumoz'

const exporter = new LumozExporter({
  apiKey: process.env.LUMOZ_API_KEY!,
  endpoint: 'https://api.lumoz.ai/proxy/v1/traces',
})
```

### Subtenant Routing

```typescript
const exporter = new LumozExporter({
  apiKey: process.env.LUMOZ_API_KEY!,
  subtenantId: 'customer-tenant-id',
})
```

## `OpenInference` semantic conventions

The LumozExporter implements [OpenInference Semantic Conventions](https://github.com/Arize-ai/openinference/tree/main/spec) for generative AI applications, providing standardized trace structure across different observability platforms.

## Tags support

The LumozExporter supports trace tagging for categorization and filtering. Tags are only applied to root spans and are mapped to the native OpenInference `tag.tags` semantic convention.

### Usage

```typescript
const result = await agent.generate('Hello', {
  tracingOptions: {
    tags: ['production', 'experiment-v2', 'user-request'],
  },
})
```
